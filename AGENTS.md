# Agent rules

- Load the `ui-craft` skill before writing or editing any UI code (components, CSS, layout), every session, no exceptions.
- Read `/DESIGN.md` (repo root) first and follow it strictly for all UI. `docs/DESIGN.md` is the older pass-4/5 history.
- Dark Mercury ink-violet surfaces (no pure black or white), one indigo accent, mono + tabular-nums for IDs, dates and money, primary/secondary/tertiary buttons, bordered amber alert, 3 type sizes, no fade-ins. Lucide icons only, no emoji, no em dashes.
- After any UI change, screenshot at 1440, 768 and 390 and check the console. Do not change app logic.
