# Flexport ACE custom report: required columns

Source: https://tariffs.flexport.com/refunds/help (fetched 2026-10-30). Flexport says column order doesn't matter, but names must match exactly.

Required (7):
1. Entry Summary Number
2. Entry Date
3. Entry Summary Line Number
4. Tariff Ordinal Number
5. HTS Number - Full
6. Line Tariff Goods Value Amount
7. Line Tariff Duty Amount

Optional: Entry Type Code, Line SPI Code, Line Tariff Quantity (1), Line Tariff UOM (1) Code, Line Tariff Quantity (2), Line Tariff UOM (2) Code, Liquidation Date, Liquidation Status.

Flexport recommends an Entry Date range of February 2025 or later.
